## 🛠️ Concepts Practiced

* `UPPER()` — Convert text to uppercase
* `LOWER()` — Convert text to lowercase
* `INITCAP()` — Convert text to title case
* `REPLACE()` — Replace characters or text
* `TRIM()` — Remove leading and trailing spaces
* `CURRENT_DATE()` — Get the current date
* `CURRENT_TIME()` — Get the current time
* `CURRENT_TIMESTAMP()` — Get the current timestamp
* `CURRENT_SCHEMA()` — Get the current schema
* `TO_CHAR()` — Format dates and timestamps
* `TO_DATE()` — Convert strings into dates
* `SHOW PARAMETERS` — View session parameters
* `ALTER SESSION` — Modify session settings
* Date and timestamp formatting
* Basic data cleaning and transformation
